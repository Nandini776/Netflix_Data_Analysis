# 🎬 Netflix Data Analysis

An **Exploratory Data Analysis (EDA)** project on the Netflix dataset using Python, Pandas, NumPy, and Matplotlib.

The project explores Netflix content based on **content type, ratings, movie duration, release years, countries, and yearly release trends** through different visualizations.

## 📊 Analysis & Visualizations

### 1. Movies vs TV Shows
**Visualization:** Bar Chart

Compared the total number of **Movies and TV Shows** available in the dataset.

📌 `Movies_VS_TVshows.png`

---

### 2. Content Rating Distribution
**Visualization:** Pie Chart

Analyzed the **percentage distribution of Netflix content across different ratings** such as TV-MA, PG-13, R, etc.

📌 `percentage_of_content_rating.png`

---

### 3. Movie Duration Distribution
**Visualization:** Histogram

Converted movie durations from text into numerical values and analyzed the distribution of **movie runtimes in minutes**.

📌 `Movies_Distribution.png`

---

### 4. Release Year vs Number of Shows
**Visualization:** Scatter Plot

Analyzed the relationship between **release year and the number of Netflix titles released**, helping identify changes in content production over time.

📌 `myear_vs_number_of_shows.png`

---

### 5. Top 10 Content-Producing Countries
**Visualization:** Horizontal Bar Chart

Split multiple-country entries and identified the **top 10 countries based on the number of Netflix titles associated with them**.

📌 `countries.pdf`

---

### 6. Movies vs TV Shows Release Trend
**Visualization:** Two Line Charts

Compared the yearly release trends of:

- Movies
- TV Shows

The project uses a **two-panel visualization** to observe how movie and TV show releases changed across different years.

📌 `subplotting.png`

---

## 🧹 Data Preprocessing

The project performs basic data cleaning before analysis:

- Removed rows containing missing values
- Extracted numerical movie duration from the `duration` column
- Split multiple countries into individual country entries
- Counted content by type, rating, country, and release year
- Grouped Movies and TV Shows by release year

## 🛠️ Tech Stack

- **Python**
- **Pandas**
- **NumPy**
- **Matplotlib**


## 🎯 Objective

The objective of this project is to understand Netflix's content library and identify patterns in:

- Movies vs TV Shows
- Content ratings
- Movie durations
- Release trends
- Country-wise content
- Movies vs TV Shows over time
